
Asistente VR Benmac - Proyecto WebVR

Este paquete contiene:
- index.html : escena A-Frame con avatar, audio y redirección
- avatar.glb : modelo 3D cartoon femenino (reemplazar por el real)
- voz.mp3 : audio generado en voz formal femenina (reemplazar por el real)

Instrucciones:
1. Puedes alojar estos archivos en Vercel, Netlify o GitHub Pages.
2. El avatar se presenta con voz y redirige automáticamente a https://benmac.edu.mx.
3. Si deseas personalizar el mensaje o avatar, reemplaza voz.mp3 y avatar.glb por nuevos archivos.

Contacto: Si necesitas ajustes, animaciones personalizadas o múltiples escenas, contáctame.
